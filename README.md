To use the tools, download the python script and the my_templates folder in one common folder on your computer.

When you run the python script from your terminal, calculator_app.py, it will open up a new tab in Google chrome with links to the following calculators:
1. Basic Calculator --> was for basic testing purposes, but I chose to keep it anyway
2. Optical magnitude to Luminosity --> converts Swift UVOT magnitudes (Vega or AB system) to luminosity (erg/s)
3. Flux to Flux Density --> Convert integrated unabsorbed flux (erg/cm2/s) to flux density (mJy)
4. Flux Density to Flux --> Convert flux density (mJy) to integrated unabsorbed flux (erg/cm2/s)
5. Significance of Detection --> Calculate detection significance of X-ray sources using Poissonian statistics
6. Count-rate Upper-limit --> Calculate the count-rate upper-limit for a non-detected X-ray source at a given (gaussian equivalent) significance level.
